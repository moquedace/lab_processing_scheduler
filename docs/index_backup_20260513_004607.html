Como funciona

O sistema permite que usuários cadastrados solicitem reservas. As solicitações são registradas no banco online, passam por aprovação administrativa quando necessário e ficam disponíveis para consulta no painel público.

1
Acesse o sistema Use o botão principal para abrir o app Shiny de reservas.
2
Solicite a reserva Selecione seu nome, computador, horário e tipo de processamento.
3
Aguarde a aprovação Reservas longas ou sensíveis podem exigir revisão administrativa.
4
Consulte o painel Acompanhe disponibilidade, próximas reservas e solicitações pendentes.
