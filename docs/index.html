Acesso ao sistema

Uma porta clara para a operação diária.

O GitHub Pages apresenta o sistema e encaminha os usuários para o app Shiny, onde ficam consulta de disponibilidade, solicitação, aprovação e auditoria.

Fluxo recomendado

Entre pelo portal, opere no Shiny.

Usuários cadastrados devem acessar o app para consultar os horários disponíveis, preencher a solicitação e acompanhar a situação da reserva.

Consulta Disponibilidade atual e próximas reservas aprovadas.
Solicitação Formulário com computador, horário, duração e demanda computacional.
Administração Aprovação, rejeição, cancelamento e registro de decisões.
Dados sensíveis

Credenciais e banco ficam fora desta página.

A página institucional não guarda senha, credenciais ou dados da planilha. O app Shiny usa variáveis de ambiente e service account para acessar o Google Sheets.

Infraestrutura

Duas estações para diferentes perfis de processamento.

A escolha do computador deve considerar volume de dados, necessidade de memória, paralelismo, uso de GPU e urgência do processamento.

Super 1

Processamento científico geral.

Reservável

Indicado para rotinas em R e Python, processamento espacial, modelagens intermediárias e tarefas com GPU de demanda moderada.

Processador 2 x Intel Xeon Gold 5120T
Núcleos 28 núcleos | 56 threads
Memória 128 GB RAM
GPU NVIDIA Quadro RTX 4000 | 8 GB
Super 2

Processamento intensivo e paralelo.

Prioritário

Recomendado para grandes mosaicos raster, alto consumo de memória, predições espaciais em larga escala e rotinas com elevado paralelismo.

Processador AMD Ryzen Threadripper PRO 7985WX
Núcleos 64 núcleos | 128 threads
Memória 512 GB RAM
GPU NVIDIA RTX 4000 Ada | 20 GB
Como funciona

Reserva com rastreabilidade e revisão quando necessário.

O fluxo foi pensado para ser simples para o usuário e transparente para a administração.

1
Acesse o app Abra o sistema Shiny pelo botão principal desta página.
2
Preencha a solicitação Informe computador, data, horário, duração e tipo de processamento.
3
Aguarde a decisão Solicitações sensíveis, longas ou conflitantes podem ir para aprovação manual.
4
Acompanhe a agenda Consulte o painel público do app para ver disponibilidade e próximas reservas.
Governança

Uso compartilhado com critérios claros.

O sistema ajuda a reduzir conflitos de agenda, registrar decisões e preservar a infraestrutura computacional do grupo.

Transparência

Agenda pública enxuta.

O app mostra disponibilidade e próximas reservas sem expor detalhes administrativos ou dados sensíveis.

Prioridade

Regras configuráveis.

Critérios como demanda computacional, prazo, duração e necessidade do computador mais adequado orientam a decisão.

Auditoria

Histórico preservado.

Aprovações, rejeições e cancelamentos ficam registrados no banco online para consulta administrativa.

Pronto para consultar ou solicitar uma reserva?

O sistema funcional abre em uma nova aba e concentra todo o fluxo operacional de reservas.
